# Sports Components E-commerce Project

A full-stack E-commerce platform for buying sports equipment and components online.

## 🛠️ Technologies
- **Backend:** Java, Spring Boot, Spring Data JPA, Spring Security
- **Frontend:** React.js, JavaScript
- **Database:** PostgreSQL
- **API:** REST API

## 📂 Project Structure
```text
spring_boot_small_e-commerce_project/
├──  Backend
└──  Frontend
```

## 🎯 Key Features
- Browse sports products
- Product details and search
- Shopping cart management
- User authentication
- Order management
