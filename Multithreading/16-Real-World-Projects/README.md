# 16 - Real-World Multithreading Projects

Small console-based exercises that combine multiple concurrency concepts.

- `BankingTransactionDemo.java`: protects a shared account balance with synchronization.
- `MultithreadedFileProcessorDemo.java`: processes a list of files concurrently using an ExecutorService.
- `EcommerceOrderProcessingDemo.java`: demonstrates independent asynchronous order steps with CompletableFuture.

These are educational examples, not production payment or banking systems.
