# 01 - Thread Basics

Learn how to create and start threads using `Thread` and `Runnable`.

- `ThreadWithRunnable.java`: create a task with Runnable.
- `ThreadWithThreadClass.java`: create a Thread subclass.
- `StartVsRun.java`: compare `start()` with a direct `run()` call.

Run each file separately with `javac FileName.java` and `java ClassName`.
